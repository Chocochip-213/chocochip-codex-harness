# 문제 유형별로 쓸 것

원칙
- 아래 방법·수치는 검토할 후보와 사용 예다. README·담당자 기준을 대신하지 않는다. 결과를 바꾸는 기준값은 출처를 확인하고, 미정이면 AGENTS.md대로 묻는다(기준을 세우는 단계는 계획이 $criteria로 표시한다).
- 후보를 비교해 고른 패키지는 `env_check.py`에 이미 있다고 나왔으면 그대로 쓰고, 없으면 설치해 쓴다(설치에 드는 분과 실패 위험은 비교할 때 비용 한 줄로 센다). 설치가 안 되면 원인을 적고 같은 행의 다른 후보로 바꾼다(사용자와 정한 것이면 바꾸기 전에 원인과 대안을 알린다). 계산 방식이 바뀌어 결과가 달라지는 선택이면 AGENTS.md대로 사용자에게 묻고, 결과가 같은 구현 부품(파일 읽기·서버 부품·테스트 도구 등)은 패키지의 설치 분과 직접 만들 때의 구현·검증 분·깨질 위험을 견줘 내가 정해 단계 보고에 이유를 적는다. 웹 서비스의 서버·화면 방식(도표가 있으면 도표 도구도)은 아래 웹 행대로 계획 때 사용자와 정하고, 고른 것은 다시 묻지 않는다. pip가 없다는 것만으로 설치 불가로 보지 않고 설치 방법을 확인한다.
- 계산 방법이 결과 품질을 좌우하면 문제를 입력·출력·제약·목적으로 다시 쓰고, 그 구조에 맞는 표준 해법과 단순 기준선을 후보로 잡는다(가장 단순한 방법의 변형만 비교하지 않는다).
- 결과를 사람이 설명할 수 있어야 한다. 방법과 패키지는 README 요구, 구조(고치기 쉬운 곳)·화면 완성도, 설치 가능성과 시간, 직접 만들어야 하는 부품의 구현·검증 시간과 깨질 위험, 결과를 설명하는 데 드는 시간을 함께 비교해 고른다. 설명하기 어려운 방법을 고르면 설명할 수 있는 기준선과 나란히 보인다.
- 작업 환경의 버전은 `env_check.py`로 다시 본다.

패키지 주의점
- matplotlib 차트: 기본 글꼴에 한글이 없어 글꼴 설정이 먼저 필요하다(설치기가 나눔고딕 파일을 `~/.cache/ui_check/bundle/fonts/`에 둔다).
- Streamlit, Datasette: 미리보기 프록시 경로에서 되는지 확인하지 않았다. 쓰면 첫 화면에서 확인한다.
- statsmodels, scikit-learn, OR-Tools: 설치 크기가 수십 MB다.
- 오프라인 wheel 묶음: 작업 환경의 파이썬·glibc 버전을 모른다. 작업 환경에서 pip가 막혀 있으면 그때 다시 정한다.
